> brute force: fix start i, move end j and accumulate the sum
> no break when sum == k, because following elements may be 0 and form another valid subarray
> Time O(n^2) Space O(1)

```csharp
public int SubarraySum(int[] nums, int k) {
    var resultCount = 0;

    for(var i = 0; i<nums.Length ;i++)
    {
        var shiftResult = 0;
        for(var j = i;j< nums.Length;j++)
        {
            shiftResult +=nums[j];

            if(shiftResult == k)
            {
                // no break here because next element is 0 then count++
                resultCount+=1;
            }
        }
    }

    return resultCount;
}
```

> prefix sum + dictionary: for the current end, subarray sum = currentSum - earlierPrefix
> so look up how many earlier prefix sums equal (currentSum - k)
> [0] = 1 stands for the empty prefix, so subarrays starting at index 0 are counted
> sliding window does not work because nums may contain negative numbers
> Time O(n) Space O(n)

```csharp
public int SubarraySum(int[] nums, int k) {

    var resultCount = 0;
    var currentSum = 0;

    var prefixSumCount = new Dictionary<int, int>
    {
        [0] = 1
    };

    foreach (var num in nums)
    {
        currentSum += num;

        // 1. find earlier prefix sums that match
        if (prefixSumCount.TryGetValue(currentSum - k, out var matchCount))
        {
            resultCount += matchCount;
        }

        // 2. record the count of the current prefix sum
        if (prefixSumCount.TryGetValue(currentSum, out var frequency))
        {
            prefixSumCount[currentSum] = frequency + 1;
        }
        else
        {
            prefixSumCount[currentSum] = 1;
        }
    }

    return resultCount;
}
```
