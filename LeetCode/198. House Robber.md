> rob(i) = the max money from house i to the end
> at house i there are only two choices: rob it and skip i + 1 -> nums[i] + rob(i + 2), or skip it -> rob(i + 1)
> rob(i) = max(nums[i] + rob(i + 2), rob(i + 1)), past the last house -> 0

> bottom-up DP + space optimization: iterate from the last house back to 0
> rob(i) only depends on rob(i + 1) and rob(i + 2), so keep two variables instead of an array
> next1 = rob(i + 1), next2 = rob(i + 2), after the loop next1 = rob(0)
> Time O(n) Space O(1)

```csharp
    public int Rob(int[] nums) {
        var next1 = 0;
        var next2 = 0;

        for(var i = nums.Length -1; i>= 0;i--)
        {
            var curr = Math.Max(nums[i]+ next2, next1);
            next2 = next1;
            next1 = curr;
        }
        return next1;
    }
```
