> use dictionary to record num -> index, look up (target - num) while iterating
> Time O(n) Space O(n)

```csharp
public int[] TwoSum(int[] nums, int target) {
    var numsIndexDict = new Dictionary<int, int>();

    for (int i = 0; i < nums.Length; i++)
    {
        var findNum = target - nums[i];
        if(numsIndexDict.TryGetValue(findNum, out int matchIndex))
            return [matchIndex,i ];

        numsIndexDict.TryAdd(nums[i], i);
    }

    return Array.Empty<int>();
}
```
