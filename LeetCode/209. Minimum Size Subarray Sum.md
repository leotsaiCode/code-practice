> all nums are positive -> expanding the window only increases the sum, shrinking only decreases it
> so a variable-size sliding window works: no need to try every subarray

> sliding window: right expands the window and adds nums[right] to tempResult
> while tempResult >= target, the window is valid -> record right - left + 1, then remove nums[left] and move left to try a shorter window
> minLength starts at int.MaxValue, if it never changes there is no valid subarray -> return 0
> each element enters and leaves the window at most once -> Time O(n) Space O(1)

```csharp
public int MinSubArrayLen(int target, int[] nums) {
        var left = 0;
        var right = 0;
        var tempResult = 0;
        var minLength = int.MaxValue;
        while (right < nums.Length)
        {
            tempResult += nums[right];

            while (tempResult >= target)
            {
                minLength = Math.Min(minLength, right - left + 1);

                tempResult -= nums[left];
                left++;
            }

            right++;
        }
        return minLength == int.MaxValue ? 0 : minLength; 
    }
```
